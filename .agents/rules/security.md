# Security Rules for AI Agents

## Confidentiality of .env and Secrets
- All AI agents working in this workspace are STRICTLY PROHIBITED from opening, reading, viewing, or searching the contents of any `.env` file (e.g. `api/.env`, `.env`, `*.env`).
- Never ask the user to paste, share, or disclose secrets, tokens, passwords, or credentials.
- When configuration names are needed, refer ONLY to `api/.env.example`.
- Never print or log secrets in transcripts, artifacts, or responses.
